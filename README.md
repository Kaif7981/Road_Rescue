# 🚗 Road Rescue – Vehicle Assistance Web Application

Road Rescue is a **Java-based web application** that provides **on-road vehicle assistance** such as fuel delivery and emergency support.  
The project is built using **JSP, Servlets, JDBC, MySQL, and Apache Tomcat**.

---

## ✨ Features
- User registration and login
- Request fuel delivery
- Book roadside assistance
- Admin dashboard to manage requests

---

## 🧰 Tech Stack
- Frontend: JSP, HTML, CSS
- Backend: Java (Servlets, JDBC)
- Database: MySQL
- Server: Apache Tomcat

---

## ▶️ How to Run
1. Import the project into VS Code or Eclipse  
2. Configure MySQL database in `DBConnection.java`  
3. Deploy the project on Apache Tomcat  
4. Open in browser:
